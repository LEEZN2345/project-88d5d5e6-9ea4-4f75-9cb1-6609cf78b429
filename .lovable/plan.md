# 东大门订货通 · 研发计划

## 一、产品定位(待你补充确认)

**一句话定位**:为东大门买手与 B 端客户提供东大门档口的全量商品信息,新款抢先、折扣促销,边逛边加购、一键下单、一键发货、全程物流跟踪。

- **目标用户**:
  - **B 端(主)**:实体服装店主、东大门职业买手、时尚自媒体/KOL、跨境电商卖家、直播带货主播
  - **C 端(辅)**:有购买力的个人时尚消费者(直接零售,客单价较高)
  - 双轨定价与权限:B 端走批发价/账期/混批,C 端走零售价/单件下单,同一商品两套价格视角
- **核心价值**:
  1. **全量货源**:覆盖东大门档口的完整 SKU,而不是片段化转发
  2. **新款抢先**:档口上新即同步,首屏推荐与订阅提醒
  3. **折扣促销**:档口活动、清仓、阶梯价集中曝光
  4. **边逛边加购**:多档口共用购物车,选款流即是下单流
  5. **一键下单 / 一键发货**:打通档口下单 → 韩国仓集货 → 国内发货
  6. **全程物流跟踪**:档口出货、仓内分拣、跨境运输、国内派送统一时间线
- **平台形态**:同一套响应式 Web,移动端为主、PC 端兼顾
- **语言/币种**:中韩双语,KRW ↔ CNY 实时汇率换算,下单锁定汇率快照

## 一·B 商业模式(三层收入结构)

1. **基础物流服务费(主力现金流)**
   - 按订单/件数/重量/体积计费,覆盖韩国仓集货、打包、跨境运输、国内派送
   - 建议结构:打包费(按件)+ 头程运费(按重/体)+ 国内派送费,平台抽取固定毛利
   - 在下单页透明显示费用明细,与商品款单分开结算,降低买手心理摩擦
2. **增值服务费(按需付费,做利润)**
   - 验货 / 质检 / 称重拍照
   - 加固包装 / 防潮 / 重新分箱 / 贴 SKU 唛头
   - 退换货代办、瑕疵索赔代谈、补单催货
   - 财务代付韩币、垫付货款(短期账期 / 资金成本)
   - 翻译沟通、档口砍价、专属采购员
3. **SaaS 会员费(锁定 B 端高频用户,做 LTV)**
   - 免费版:基础浏览 + 下单 + 标准物流
   - 会员版(月/年订阅):新款抢先推送、折扣专享、批量下单/导入、对账报表导出、专属客服、降低物流/服务费率、批发价开放、账期额度
   - 团队版:多账号协作(老板 + 采购 + 财务)、权限分级、店铺数据看板

> 设计含义:订单与账单模型必须区分 **货款 / 物流费 / 增值服务费 / 会员费** 四类流水,分别开票与对账;权限系统要支持"会员等级 → 价格视角 / 费率 / 功能开关"。

> 待你补充:目标用户更细颗粒(单兵代购 vs 批发商占比)、首批种子档口与种子买手获取方式、与现有竞品(韩都依舍、东大门 Buy 等)的差异承诺。

## 二、信息架构(初稿)

```text
[移动端 买手]
  首页 / 选款流          —— Banner、热门档口、上新、收藏
  档口详情 / 商品详情     —— 图集、款号、规格、价格(KRW+CNY)
  购物车(多档口分组)    —— 备注、混批、合并下单
  订单中心               —— 状态流转、对账、退换
  物流追踪               —— 韩国仓 → 集运 → 国内派送
  我的                   —— 收货地址、汇率、账户、客服
[PC 运营后台 v2]
  商品/档口管理、订单流、对账、汇率/费率、用户、报表
```

## 三、技术栈

- 前端:TanStack Start(SSR)+ React 19 + Tailwind v4 + shadcn,响应式优先移动端
- 后端:Lovable Cloud(Postgres + Auth + Storage + Server Functions)
- 关键能力:多档口购物车、订单状态机、汇率快照、物流时间线、图片大量上传 CDN
- 国际化:中韩双语词典 + 汇率服务(每日定时拉取,下单时锁定汇率快照)

## 四、里程碑(建议 4 个 Sprint)

### M0 · 产品与设计基线(本轮 + 下一轮)
- 你讲完定位 → 我整理一页 PRD(用户/场景/价值/指标/范围)
- 选定设计方向(我会用 design directions 出 3 个视觉风格供你挑)
- 确认数据模型草案与状态机

### M1 · MVP 浏览与下单(可点可下)
- 账号体系(手机号/邮箱登录,买手角色)
- 档口与商品浏览、搜索、收藏
- 购物车(多档口分组) + 下单 + 汇率快照
- 订单中心(状态:待付款 / 待发货 / 在途 / 已签收 / 售后)

### M2 · 对账与物流闭环
- 账单与对账(订单明细、补差、退款记录)
- 物流时间线(韩国打包 → 集运 → 清关 → 国内派送)
- 消息中心 / 推送(订单与物流变更)

### M3 · 运营后台与增长
- PC 后台:商品/订单/汇率/费率/用户/报表
- 选款推荐、收藏夹分享、邀请买手
- 数据看板(GMV、复购、爆款、退货率)

## 六、关键风险与决策点(请你在讲定位时一并回答)

1. **货源数据来源**:商家自助入驻、运营手动维护,还是抓取/合作?
2. **支付与对账**:线上收款(微信/支付宝)还是线下转账 + 平台对账?
3. **物流模式**:平台自营集运,还是对接第三方集运 API?
4. **冷启动**:先做"看款 + 下单工具"给现有买手,还是直接撮合档口?
5. **合规**:跨境电商资质、个人信息出境、KRW 收款主体在哪一方?
