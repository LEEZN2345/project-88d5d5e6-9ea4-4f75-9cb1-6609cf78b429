# 引用订单发帖 + 返佣重构方案

## 一、核心机制变更
- 发帖必须引用一条已支付的订单（1 单 1 帖），订单号作为凭证不可修改
- 创作返佣从 10% 调整为 **3%**，自购也可拿（真实消费鼓励分享）
- 邀请返佣调整为 **L1 0.5% + L2 0.2%**（旧值 0.7%/0.3%）
- 归因规则：点击帖子链接下单 → 创作返佣；未点击直接搜索下单 → 邀请返佣。二者互斥，不叠加
- 同一用户通过自己链接复购同一商品：前 2 单有佣金，第 3 单起作废

## 二、页面改动

### 发帖入口（两条路径统一到"引用订单"）
1. **`/orders/:id` 订单详情**：签收/已支付后增加「分享心得」按钮 → 跳 `/discover/new?orderId=xxx`
2. **`/discover` 顶部发帖按钮**：进入 `/discover/new` 后要求先选择一条已购订单（弹层展示我的可发帖订单列表：未发过帖的订单）

### `/discover/new` 发布器改造
- 顶部显示引用的订单卡片（订单号 + 商品缩略图，不可修改）
- 移除原"搜索商品挂链接"逻辑，改为从订单自动带入商品
- 佣金展示改为 3%
- 无 `orderId` 或订单已发过帖 → 提示"请先购买后再分享"，禁用发布

### `/me/posts` 我的分销
- 收益、佣金字段按 3% 重算
- 增加"重复自购已作废单数"提示

### `/invite-rules` 邀请规则页
- 数字改为 L1 0.5% / L2 0.2%
- 增加"与创作返佣互斥"说明

### `/membership` 会员权益页
- 按最终权益表重写：普通会员 ¥99 / 创作者会员 ¥199
- 明确：普通会员创作返佣仅可抵扣，创作者会员可提现（满 ¥50 起）
- 开卡礼、发帖权限、包邮、积分加速等分列

### `/admin/commission` 后台佣金配置
- 创作返佣比例默认 3%
- 邀请返佣 L1 0.5% / L2 0.2%
- 新增"同商品自购返佣上限次数"字段（默认 2）

### `/admin/feedback`（帖子审核，如无则在 discover 管理内加）
- 风控红线：虚假晒单、单日 >3 篇、同设备多账号、内容低质
- 状态：待审核 / 通过 / 驳回，驳回原因可填

## 三、数据/逻辑（前端 mock 层）
- `mock-data.ts` 订单类型增加 `postId?: string` 标记是否已发帖
- 发帖 mock：校验 `orderId` 存在且未被引用
- 佣金常量：`CREATOR_COMMISSION_RATE = 0.03`，`INVITE_L1 = 0.005`，`INVITE_L2 = 0.002`

## 四、不改动
- 积分规则（另议）
- 拼单/多件购买加成
- 订单主链路
