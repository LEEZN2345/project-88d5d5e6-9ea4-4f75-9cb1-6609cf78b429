## 目标
按上传的 6 张参考图重构 `src/routes/products.$id.tsx`，把当前"图 + 颜色 + 尺码 + 底部两按钮"的静态版换成"傻瓜式"下单页，突出**三档购买方式**与**档口批发价（拼单价）居中默认**。

```text

   - 大字：当前选中档位价（默认档口批发价/拼单价 ₩850）

   - 徽标：拼单省 ¥40（相对单人直购）
   - 汇率提示条（图 5 灰色小卡）：韩国代付时锁定
4. 档口信息（保留原卡片：MILK 女装 · Migliore · 2F-A41 · 进入档口→）
5. 颜色 / 尺码 选择（保留）
6. ⭐ 购买方式三选一卡片（本次重点）

   - 默认选中"拼单团购"（居中卡）
```

## 交互规则

- **默认档位**：拼单团购（居中卡）——价格显示居中且高亮。
- **切换档位**：整个价格区、悬浮栏按钮文案 & 金额、数量、下方补充说明同步刷新。
- **双件批发**：数量强制 2，隐藏数量选择/加购按钮，仅显示"立即购 2 件 ₩1640"。
- **拼单失败提示**：24 小时未成团 → 前端仅展示话术，实际逻辑后端。
- 三档单价用常量数组配置，方便后续接入商品维度定价：
  ```ts
  const TIERS = [
    { key: 'solo',  label: '单人直购', unit: 890.40, qty: 1, tag: '推荐',   accent: 'emerald' },
    { key: 'group', label: '拼单团购', unit: 850.00, qty: 1, tag: '性价比', accent: 'sky',    default: true },
    { key: 'bulk',  label: '双件批发', unit: 820.00, qty: 2, tag: '最低价', accent: 'amber' },
  ];
  ```
  数值先按参考图 hard-code；真实来源应为 `Product` 的定价字段（本轮不改数据模型，留 TODO）。
